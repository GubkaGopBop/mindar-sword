# Задание 2 — MindAR + A-Frame

Минимальная WebAR-страница без пользовательского интерфейса. После разрешения доступа к камере 3D-модель меча появляется при распознавании изображения `sword.png`.

## Файлы

- `index.html` — сцена A-Frame с компонентами MindAR;
- `sword.png` — исходное изображение-маркер;
- `targets.mind` — скомпилированный таргет MindAR для `sword.png`;
- `assets/model.glb` — локальная 3D-модель меча в формате glTF/GLB;
- `.nojekyll` — отключение обработки Jekyll на GitHub Pages.

## Проверка

Камера не запускается при открытии HTML как обычного локального файла. Для проверки на компьютере запустите HTTP-сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Изображение `sword.png` нужно показать камере на другом экране или распечатать.

На телефоне используйте опубликованную HTTPS-ссылку GitHub Pages и разрешите браузеру доступ к камере.

## GitHub Pages

1. Создайте отдельный публичный репозиторий.
2. Загрузите всё содержимое папки `Пр2` в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

Страница не содержит кнопок, текста, рамок или индикатора сканирования. Системный запрос браузера на доступ к камере отключить нельзя.
